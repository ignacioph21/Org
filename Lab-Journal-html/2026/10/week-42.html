[12:07] Tercera iteración: qué set de curvas random se usó en 10forzados

Día de medición de la Tercera iteración (cuba grande, rampa impresa 5 cm). En el motor quedó cargado el mismo forzado que en la Segunda iteración: Curvasrandom3.

Por qué la 3 y no la 2

  • Hay tres sets en el pendrive KINGSTON, Posgrado/Pruebas rampa impresa 3D cuba grande/Segunda iteración/Curvas forzado/ (copias idénticas en Tercera iteración/). En la compu solo estaban copiadas Curvas_random_! y Curvas_random_2.
  • Ningún registro dice qué set se usó en 10forzados (19/06): el 10_forzados_metadata.json solo tiene fs, canales y fecha, y no hay Command Table exportada (.lmc). Por la señal (autocorrelación, intervalos entre eventos) no se puede distinguir: las rompientes decorrelacionan demasiado.
  • La diferencia entre la 2 y la 3 es el ruido que se le suma a la forma base (subida tanh + bajada lineal), con el mismo nivel de ruido como fracción de A:
Set Generador Ruido | a | máx [mm/s²] | v | máx [mm/s] Creada
Curvasrandom2 generador_curvas_random_con_tiempo.py gaussiano blanco, punto a punto 34 000–62 000 (3,5–6 g) 700–1150 18/06 09:49
Curvasrandom3 generador_curvas_random_suaves_con_tiempo.py 8 senos entre 0,05 y 4 Hz 3 900–7 100 (0,4–0,7 g) 470–710 18/06 11:21
  • En ambos: 10 curvas de 1600 puntos, A = 92–110 mm, Tau = 610–790, T = 12,6–16,8 s. Ciclo: 147,11 s (set 2) y 145,69 s (set 3).
  • El ruido blanco agitaba demasiado al motor (saltos de varios mm entre muestras, p. ej. 2,41 → 0,05 mm en 8,7 ms) → se hizo el generador suave y se usó la 3. Confirmado por mí.
  • Para identificar en LinMot Talk qué set está cargado: el nombre de la curva son los primeros 22 caracteres del archivo, curva_00_A_107.43_Tau_ (set 3) vs curva_00_A_96.74_Tau_6 (set 2).

Guías usadas para cargar el motor

Repo del LTG: Comunicacion-con-instrumentos → Actuadores lineales/.

  • Carga de curvas con LinRS: drive del lab con --id 0x3f --baud 57600; S3.4 en On para cargar y de nuevo en Off después.
  • Selección de curvas con Command Table: Run Mode en Command Table Mode, homing, Start Command Table Command (200xh) con Entry ID 1.
